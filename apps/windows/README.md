# Windows applications

## [Mac Controls for Windows](mac-controls)

Maps physical Left Win and Left Alt to the fundamental macOS text-navigation,
selection, deletion, and symbol-entry model while preserving the existing
personal Y/Z, layout-key, and Alt+J mappings.

## [App Exposé](app-expose)

Shows only the windows of the currently focused application in a Windows Task
View-like overview. Invoke it globally with **Right Windows + -**.
